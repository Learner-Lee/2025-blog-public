# 哈希（Hash）基础知识

## 一、什么是哈希？

**哈希（Hash）就是将任意长度的数据，通过哈希算法，转换成固定长度或固定范围的值。**

可以简单理解为：

> 哈希 = 给数据生成一个“数字指纹”。

基本过程：

```text
原始数据（Input）
       ↓
   Hash 算法
       ↓
  哈希值（Hash Value）
```

例如：

```text
"apple"  → Hash → "92A1F0"
"banana" → Hash → "C81B24"
"hello"  → Hash → "2CF24D"
```

注意：以上哈希值只是示意，并非真实计算结果。

## 二、哈希的主要特点

| 特点 | 说明 |
|---|---|
| 确定性 | 相同的数据使用相同算法，得到相同哈希值 |
| 计算高效 | 很多哈希算法可以快速计算 |
| 哈希冲突 | 不同输入可能产生相同哈希值 |
| 固定长度 | SHA-256 等算法输出固定长度 |
| 单向性 | 安全的密码学哈希算法难以逆向还原输入 |

**特别注意：**

- 哈希不等于加密。
- 普通哈希算法不一定具有密码学安全性。
- 不同的哈希算法具有不同的设计目标。

## 三、哈希的实际应用

### 1. 哈希表（Hash Table）

哈希表是一种通过哈希函数快速定位数据的数据结构。

例如 Python 字典：

```python
student = {
    "Alice": 90,
    "Bob": 85,
    "Charlie": 95
}

print(student["Bob"])  # 85
```

查找过程可以简单理解为：

```text
Key = "Bob"
      ↓
计算 hash("Bob")
      ↓
确定哈希表位置
      ↓
找到 Value = 85
```

哈希表常见操作的平均时间复杂度：

| 操作 | 平均时间复杂度 |
|---|---|
| 查找 | O(1) |
| 插入 | O(1) |
| 删除 | O(1) |

注意：O(1) 是通常情况下的平均复杂度，并不保证所有情况都是 O(1)。

### 2. 文件完整性校验

可以使用 SHA-256 计算文件的哈希摘要。

```text
原始文件
   ↓
 SHA-256
   ↓
文件哈希值
```

如果文件内容发生改变，哈希值通常也会发生变化。

应用场景：

- Git 文件内容管理
- 软件安装包完整性校验
- 文件去重
- 数据传输校验

Python 示例：

```python
import hashlib

data = b"hello"

result = hashlib.sha256(data).hexdigest()

print(result)
```

### 3. 密码存储

网站不应该直接保存明文密码。

正确做法是使用专门设计的密码哈希算法，例如 Argon2id。

```text
用户输入密码
      ↓
专用密码哈希算法 + Salt
      ↓
存储密码哈希信息
```

再次登录时：

```text
用户输入密码
      ↓
利用存储的哈希信息验证
      ↓
判断密码是否正确
```

注意：普通的 SHA-256 不适合直接用于密码存储，应使用 Argon2id、scrypt 等专用密码哈希算法。

## 四、什么是哈希冲突？

**哈希冲突（Hash Collision）指不同输入产生了相同哈希值。**

例如，假设一个简化的哈希函数：

```python
def hash_function(x):
    return x % 5
```

那么：

```text
hash(7)  = 2
hash(12) = 2
hash(17) = 2
```

虽然输入不同，但得到相同的哈希值。

这就是哈希冲突。

常见解决方法：

1. **链地址法（Separate Chaining）**：同一个位置存储多个元素，例如通过链表或其他结构管理。
2. **开放寻址法（Open Addressing）**：发生冲突时，按照一定规则寻找其他可用位置。

## 五、哈希与加密的区别

| 比较维度 | 哈希（Hash） | 加密（Encryption） |
|---|---|---|
| 主要目的 | 生成摘要、索引、校验 | 保护数据机密性 |
| 能否还原 | 密码学哈希通常难以逆向还原 | 持有正确密钥可以解密 |
| 输出长度 | 取决于算法，常见为固定长度 | 取决于算法和输入 |
| 常见算法 | SHA-256、MurmurHash | AES、RSA |
| 应用场景 | 哈希表、校验、密码存储 | 安全通信、数据加密 |

## 六、总结与快速复习

### 核心记忆

> **哈希 = 数据 → 哈希函数 → 哈希值**

三个典型应用：

- **哈希表**：通过哈希值快速查找数据，平均 O(1)。
- **哈希校验**：比较摘要，检测数据是否发生改变。
- **密码哈希**：通过专用算法验证密码，无需保存明文密码。
