# 用 macOS 原生功能替代超级右键付费 App

> 目标：在不购买第三方 App 的情况下，用苹果自带功能实现「右击打开终端、复制路径、新建文件、用指定软件打开」。
>
> **结论：四个功能里有三个可以零成本用系统自带功能实现，只有「新建文件」需要自己免费配置一次。**

| 功能 | 是否需要付费 App | 实现方式 |
| --- | --- | --- |
| 右键打开终端（当前目录） | ❌ 不需要 | 系统自带服务，开启即可 |
| 复制路径 | ❌ 不需要 | 系统自带，按 Option 键 |
| 用指定软件打开 | ❌ 不需要 | 系统自带「打开方式」 |
| 新建文件 | ❌ 不需要（但需配置一次） | 快捷指令 或 Automator |

---

## 1. 右键打开终端（当前目录）— 系统自带，只需开启

macOS 内置此服务，默认关闭。开启步骤：

1. 打开 **系统设置 → 键盘 → 键盘快捷键 → 服务 → 文件与文件夹**
2. 勾选 **「在文件夹中新建终端窗口」**（New Terminal at Folder）

开启后：

- 右键文件夹 → **服务** 里即可看到该选项。
- 可在此界面直接为它**指定一个键盘快捷键**，选中文件夹按快捷键即可开终端。

无需任何第三方 App。

## 2. 复制路径 — 系统自带，零配置

- 右键文件后**按住 Option 键**，菜单里的「拷贝 xxx」会变成 **「将 xxx 拷贝为路径名」**。
- 想要纯键盘操作，可用下方 Automator 方法做一个动作再绑定快捷键。

## 3. 用指定软件打开 — 系统自带

- 右键 → **「打开方式」** 即原生功能。
- 想让某类文件长期固定用某软件打开：
  - 右键 → 打开方式 → **「其他」** → 勾选 **「始终以此方式打开」**；或
  - 在 **「显示简介」** 里设置默认 App。

无需第三方。

## 4. 新建文件 — 唯一需要配置一次（仍然免费）

这是 macOS 唯一原生没有的功能。两种免费做法，**二选一**：

### 方法 A：快捷指令 App（Shortcuts）

1. 新建一个快捷指令。
2. 使用「文本 → 存储到文件」之类的动作，在指定位置生成文件。
3. 为该快捷指令**绑定全局键盘快捷键**，按一下即可新建文件。

### 方法 B：Automator 快速操作

1. 新建 **「快速操作」**。
2. 工作流设置：**「工作流程收到当前 [文件夹] 位于 [访达]」**（即只接收文件夹，避免选中文件时脚本失败）。
3. 添加 **「运行 Shell 脚本」** 动作，并把 **「传递输入」（Pass input）设为「作为参数」（as arguments）**——默认是「输入到 stdin」，那样 `$1` 会是空的，文件会被创建到 `/` 而不是所选文件夹。脚本例如：

   ```bash
   touch "$1/未命名.txt"
   ```

   > 若想保留「文件或文件夹」两种输入，可改用下面的脚本，自动判断选中的是文件还是文件夹：
   >
   > ```bash
   > target="$1"
   > [ -d "$target" ] || target="$(dirname "$target")"
   > touch "$target/未命名.txt"
   > ```

4. 保存后，右键 → **快速操作** 里即可使用，也能在键盘设置里绑定快捷键。
