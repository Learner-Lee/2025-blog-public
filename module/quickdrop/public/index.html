第一次使用？看看怎么传
  1. 两台设备打开 QuickDrop，用同一配对链接加入房间。
  2. 核对两端的六位配对码，并分别确认。
  3. 一次选择多个文件时，对方只需确认接收整组一次。文件明细默认折叠，可按需展开。
  4. 整组传完并校验后，点击“打包下载 ZIP”；解压后是一个文件夹。单个文件仍可直接下载。

单文件上限 512 MiB，每组最多 1024 MiB、50 个文件。一次选择超过组容量或数量时，会按文件名自然顺序自动拆成多组，依次发送；每组只需确认一次。同名文件打包时会自动编号，避免覆盖。文件下载保存后，可点击任务内的“释放缓存”回收本页内存。双方需刷新到新版页面后使用新的大小限制和自动分组。

微信：打开文件 → 右上角菜单 → 用其他应用打开 / 保存到“文件”（以版本实际菜单为准）。QQ：先下载文件，再保存或使用“其他应用打开”。安卓若选择器找不到聊天文件，可先保存到 Download 等系统目录。

双方需保持页面打开。接收文件与打包操作均在浏览器内存中进行，关闭页面后无法继续下载。跨网络直连不可用时会尝试中继；中继同样传输加密数据。网络切换或手机锁屏可能中断传输，当前不支持断点续传。
